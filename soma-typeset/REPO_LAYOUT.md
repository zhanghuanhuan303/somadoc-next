# Repository layout (open-source snapshot)

This repository is the complete `soma-typeset` workspace. The README is the
long-form engineering record; `docs/soma-atlas.html` is the dated current map.

```
soma-typeset/
├── crates/                 # 28 Rust crates: engine, frontends, renderers, CLI, Studio
├── corpus/                 # CC-BY-4.0 evaluation corpus
├── docs/                   # atlas, architecture, 120 ADRs, debt, reports, deployment example
├── examples/               # book/template/diagram samples; no generated output
├── scripts/                # gates, samples, browser bundle, local Studio assets
├── tools/                  # metrics generator and dry-run panel
├── web/                    # standalone K-P browser slice + demo
├── CONTRIBUTING.md
├── SECURITY.md
├── CODE_OF_CONDUCT.md
├── NOTICE
├── PROVENANCE.md
├── LICENSE                 # Apache-2.0
└── Cargo.toml
```

## What is intentionally not committed

- `target/`, `dist/`, generated PDFs/SVG/HTML sample output.
- Browser GB2312 font subsets (generated by `scripts/local-assets.sh`).
- The full CJK/TTF font files; only the math face required by the CLI is
  bundled, with its GUST license text.
- Deployment credentials, environment files and host-specific runbooks.

## Quick verification after a fresh clone

```sh
cargo test --workspace
bash scripts/gates.sh
```

The Studio needs `trunk`, Chromium (for S gates) and a font directory:

```sh
(cd crates/soma-studio-ui && trunk build --release)
SOMA_FONT_DIR=/path/to/fonts bash scripts/local-assets.sh
bash scripts/studio.sh
```
