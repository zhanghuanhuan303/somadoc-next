# Dry run (simulated panel)

**This directory contains no human data.** `simulated-preferences.csv` is
generated by `tools/dry-run-panel/panel.py` (fixed arithmetic rule: `A` when
`(paragraph*7 + evaluator*13) % 10 < 6`), and `report.md` is its only output.

The dry run exists so that the whole chain — kit generation, key handling,
CSV parsing, Wilson interval, Fleiss' kappa, decision rule — is reproducible
without waiting for a human panel. `crates/soma-eval/tests/blind_pipeline.rs`
runs the same files in CI.

Regenerate:

```sh
python3 tools/dry-run-panel/panel.py
cargo run -p soma-eval -- blind \
  corpus/blind/dry-run/simulated-preferences.csv \
  --key corpus/blind/dry-run/kit-key.csv \
  --out corpus/blind/dry-run/report.md
```

The printed decision is `Inconclusive`, which is the correct outcome for a
panel whose decoded preference is not a clear win. **It is not a quality
claim** and must never be cited as one. Gate Q / D01 stay open until a real
panel fills `corpus/blind/kit/ratings.template.csv`.

[`docs/blind-dry-run.md`](../../../docs/blind-dry-run.md).
