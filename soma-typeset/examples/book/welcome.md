# Soma Studio 使用说明

这是一份**可以直接修改**的说明文件。左侧是 Markdown 源文，右侧是同一份内容在浏览器里实时排版的结果；断行、分页、标点挤压与 PDF 导出都在本地完成，不需要服务器参与计算。

把下面的内容换成你的稿子即可。模板决定版式，源文只描述结构。

## 怎么用

1. 在左侧编辑这份 Markdown，右侧会立即重新排版。
2. 用顶部的「校样 / 源文 / 检视 / 校验」切换视图。
3. 点「导出 PDF」在浏览器里生成文件；第一次会加载字体，之后走缓存。
4. 如果想使用服务端的文件树和 native 对照，在地址后加 `?server=1`。

## 行内与段落

普通正文会自动处理中英文混排、标点禁则和行边裁剪。你可以写**加粗**、*斜体*、`行内代码`，也可以直接插入 LaTeX 行内公式，例如 $E = mc^2$ 与 $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$。

> 引用块用来区分另一种声音。它的左右缩进由模板决定，不需要在源文里手动加空格。

列表适合步骤和并列项：

- 第一层：断行是全局优化
- 第二层：标点禁则与行边裁剪
  - 嵌套项仍然共用同一套度量
- 最后一项：PDF 与校样来自同一次布局

脚注会落在当前页底部，并参与页面高度的计算。\footnote{脚注不是排完正文再补，而是和正文一起求解；过高的脚注会把正文挤到下一页。}这也是为什么导出 PDF 时不需要再请求服务器。

## 版式从哪来

标题层级、表格线、页边距、页眉页脚、目录与封面都来自模板，而不是这份 Markdown。当前线上默认使用 Plex 模板和 `proposal-v1` 引擎参数；改模板会改变版式，但不会改变断行内核的确定性。

## 边界

- 浏览器版本内置 GB2312 一、二级字库的子集；超出该字集的生僻字可能显示为空框。
- 这份线上稿是单文件模式；打开任意本地文件需要服务端文件树（`?server=1`）。
- 数学、表格、代码块、脚注与引用都在同一个 DocIR 里，导出 PDF 与右侧校样走同一次布局。
