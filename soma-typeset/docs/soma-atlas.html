§0摘要 · 当期状态一页

一句话：把「中文排版难做」拆成可验证的工程问题——两级 IR、规则与算法分离、 六层参数、整数定点、跨端同哈希——然后把每一层都做到能被门禁重跑。 排版质量用自己的代价模型与暴力参考解对齐，而不是拿别人的引擎当 oracle。本图集沿用「图集」而不是「报告」的写法：先给数字与图，再给口径与出处；读者可以从任一数据点回到对应的脚本、ADR 或语料行。

三条口径声明（先读）

  1. 「可复现」指同输入同字节：canonical JSON 的字段顺序、整数舍入、迭代顺序都固定；跨目标只比较同一 schema 的字节。
  2. 「优于贪心」是同一代价模型下的最优性：K-P 与 Greedy-C 读同一套代价；我们不拿 TeX/Typst 的输出当 oracle。
  3. 「对标 LaTeX」是版式口径，不是实现移植：默认版式是 Plex 参考页（ADR-0088），LaTeX article 归档为可选项；数学按 TeXbook 附录 G 与字体 MATH 表实现，clean-room。

§1缘起 · 三个研究问题

  1. 中文优先能不能不是「事后补丁」？——把标点、挤压、禁则、行边裁剪做成规则层， 断行内核只认宽度与边界属性。代价是规则层与布局层之间要有一条干净的 seam； 收益是换字体、换模板、换语言都不用动 DP。这条 seam 的验收是「breaker 不认识中文规则」：内核只看 Atom/Boundary，规则表只产生 compress_left/right 与可断性。
  2. 全局优化能不能做到可解释、可标定？——放弃 TeX 的平方 demerits，用加法加权代价， 每项先归一化、各有独立权重；再用暴力枚举锁住「我们的最优」。代价是失去 TeX 几十年调参先验， 收益是每个决策都能从 trace 读出原因。
  3. 跨端可复现能不能是硬约束？——全整数、固定顺序、canonical 字节、同哈希门禁。 代价是所有几何都要在 1/4096 em 网格上做整数运算；收益是 native、wasm、不同宿主的输出可以逐字节对拍。

押注的结果：一期 8 个阶段（K1–K8）+ 架构 A1–A6 + 能力 E1–Q′ + 字体 F1–F5 + 数学 M1–M7 全部落地。 这条路径的边界与代价写在 §6/§7。

§3架构总览 · 一条管线、两条 seam

管线只有一条，每一层只知道下一层的契约。两个 seam 是整个设计的关键： 规则层把「中文」变成原子与边界的属性；度量层把「字体」变成宽度与墨迹。 断行与分页都只读这两层的结果，因此可以独立测试、独立替换、独立复现。

三条硬纪律

  • 内核冻结：行内 K-P 的 DP、代价、tie-break 不再改；只允许默认 0、不改变既有行为的字段扩展（ADR-0007）。
  • 文档不带物理样式：DocIR 只有语义；字号、行距、缩进、颜色都在模板里（ADR-0009）。
  • 模板不带引擎参数：preset、搜索窗口、回退阶梯属于 soma.engine/1；模板只描述版面（Gate A 静态检查）。

§5工程方法 · 为什么这些数字可信

5.1 ADR 先于代码

92 份 ADR 不是事后文档，而是决策记录：每个非平凡选择都先写「Context / Decision / Consequences / Alternatives」，再动代码。冻结后的架构只允许由新 ADR 扩展， 所以「为什么现在不这样做」与「以后怎么做」都能查到。

5.2 每次行为变化都先解释基线

语料基线、Gate V 的 SVG 字节哈希、native/wasm 同哈希、ADRs 里的数字——任何一项变化 都必须在提交信息里写出原因，并在相应文档里更新解释。这条纪律的价值在数学 v2 中体现得最清楚： 盒高从 em 盒改成墨迹盒后，所有含公式的页面都重排了，但语料 ALL 行没有动， 因为数学不在 publish-v1 的语料路径上——这个结论必须被验证，而不是假设。

5.3 clean-room 与来源

核心不读 Typst 断行源码，不复制竞品规则表；规则条目带 ruleId 与来源， 未核实条目只能产生软约束。数学只依据 OpenType MATH 规范与 TeXbook 附录 G 的规则， 不移植任何实现。

§6踩坑档案 · 十二则

都是实际发生过的：每条都有「现象 → 根因 → 修复」。这一类问题通常不会让程序崩溃， 只会让输出「看起来不对」，所以只能靠 golden/不变量抓。

  1. 页码消失。页脚行把 line_height 设成 0，DocIR 的 InvalidLineHeight 让 paragraph_from_text 返回 Err， margin block 返回 None，页码静默不发射。修复：页脚行用自然行盒， band 高度由 block 承担，并为「页脚贴带底」加 golden。
  2. 根号长腿。根式横线按字面 ascent 定位，而 π 的墨迹只有 0.44em。 修复：度量表记录每字形纵向墨迹，vinculum 贴墨迹顶；M1–M4。
  3. 数学常数错位。OpenType 的 MathConstants 是 4 个 plain 字段 + 51 个 MathValueRecord + 1 个 trailing percent；按「54 个 int16」解析时， overbar 的 rule 变成 350‰。修复：按 4 字节记录解析，并用 HarfBuzz 的枚举顺序核对。
  4. 嵌套上标越缩越小。scriptscript_scale 从未被读取，每层都乘 0.7。 修复：脚本尺寸按公式基础字号算，S→SS 后不再缩。
  5. \! 是空操作。解析成 Space(0)，而 Space 存不了负数； 文档却写着 −167。修复：改用有符号 space。
  6. Bin 归一化只做了一半。x=-1 中 - 的右侧仍按 Bin 加 4mu。 修复：左右两遍归一化，单个原子的类同时用于两侧。
  7. 行内公式断了但空了。拆分的边界带了数学间距，若把它当普通空格，断行后行尾会多一段空白。 修复：间距作为 boundary 的 glue，断行时自然丢弃。
  8. SVG 视觉锁误报。页脚从带顶移到带底，SVG 字节变了；但正文坐标没变。 修复：哈希注释写明「只有 margin block 位置变化」，而不是盲目更新。
  9. 模板属性静默丢失。PROPERTY_ORDER 漏加一个属性，YAML 解析不报错， 样式就是不生效。修复：把白名单当契约，属性测试覆盖每个名字。
  10. 表格列宽一律平分。中文「短列 + 长列」被挤成竖条。修复：先量自然宽， 再按比例分配，最大余数法保证和等于版心（D90 关闭）。
  11. 续排表头孤行。表头落在页底，正文从下一页开始。修复：表头与首个行带 can_break = false，续排页重复表头。
  12. 垂直页坏度的 body 参照取错。用「页首项高度」当归一化基准，页首是图时半页空白只算 86 点坏度， DP 宁愿留洞。现状：D92 已登记，尚未修；修法是把 body 改用正文行高。

工具
tools/metrics-gen：字体度量表；scripts/：门禁与样张

9.3 术语

Atom
断行的最小单位：一个汉字、一个拉丁 run、一个对象（公式/图片/注音基）。
Boundary
两个 atom 之间的边界：可断性（Allowed/Forbidden/Forced）、glue、penalty、角色。
Box Tree
语义 + 模板解析后的物理盒：块、行、坐标、样式 id。
K-P
Knuth–Plass：全局最小的断行/分页动态规划；本项目用加法代价与整数 DP。
Trim
行边裁剪：行首/行尾的标点侧空、悬挂标点，上限由规则层给出。
Fallback ladder
正常 → relaxed → emergency → forbidden rescue；每阶段有独立标记与代价。
Canonical
固定字段顺序、整数、无浮点的字节输出；跨目标比较的对象。
Cramped
TeX 的紧排 style：分母等位置使用，避免上标与分数线相撞。
