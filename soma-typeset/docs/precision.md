# 精度敏感性：1/4096 em 的量化会不会改变断行

状态：**实测完成**。工具是 `crates/soma-eval/tests/perturbation.rs`（`#[ignore]`，不进常规门禁）。

## 问题

布局全部使用 1/4096 em 的整数定点，没有浮点。一个自然的担心是：字宽量化误差会不会让 K-P 选错断点，导致「不够完美」。

## 方法

- 度量：`soma-metrics` 的 Noto 表（与 Gate Q′ 相同），样式模板 `soma_eval::score::TEMPLATE`（A5、10.5pt、两端对齐），参数 `publish-v1`，垂直 K-P。
- 语料：`corpus/zh` 的 9 篇真实文本 + 表格页 + 公式页 + 30 页书稿，共 **606 块 / 1213 行**。
- 扰动：包一层 `Metrics`，只改 `advance` / `space_width`，因此断行看到的字宽与基线不同：
  - `zero`：对照组，必须 0 差异；
  - `jitter`：每个码位按确定性哈希取 `-1/0/+1`，模拟「另一种同样合法的舍入」；
  - `plus-one` / `minus-one`：每个字形统一 `+1` / `-1`，这是比真实舍入更狠的系统性上界。
- 比较：按 `NodeId` 收集每块的 `(line.start, line.end)` 序列，统计断点位置变化、页数与降级行。

## 结果

| 模式 | 断点变化的块 | 变化的行位置 | 页数 |
|---|---|---|---|
| 对照 `zero` | 0 / 606 | 0 / 1213 | 48 |
| `jitter`（±1 随机） | **0 / 606（0%）** | **0 / 1213（0%）** | 48 |
| `plus-one`（全部 +1） | 1 / 606（0.165%） | 2 / 1213（0.165%） | 48 |
| `minus-one`（全部 −1） | 4 / 606（0.660%） | 17 / 1213（1.401%） | 48 |

分文档看，只有 4 篇在 `minus-one` 下变化（editorial、interview、science、technical），其余 8 篇（含 30 页书稿、表格页、公式页）在任何模式下都逐行一致。

一个值得记录的边界效应：`editorial` 在 `minus-one` 下从 2 页变成 1 页，少了一行，并出现 1 行 `overfull`。这不是断点精度变差，而是**分页处在临界点**：整份文档缩了不到 0.01em/行，最后一行刚好被拉回上一页。分页对 1 单位的敏感度高于行内断点，这是正常的离散边界现象。

## 结论

- 1/4096 em 不是断行质量的瓶颈：真实舍入形态（`jitter`）下 **0%** 的断点变化；即使把所有字宽系统性偏移 1 单位，也只有 0.17%–1.4% 的行位置变化。
- 浮点不会让 DP 更「正确」：K-P 在整数代价模型上是精确最短路，浮点只会让近乎并列的候选随机换位，并破坏 native/wasm 同哈希。
- 更大的误差源是度量表保真度（kerning、粗体 advance、字体面）和代价模型（boundary deviation 近似、无 fitness、无 hyphenation），不是 1/4096。
- 结论：**保持整数**。若要进一步提高与真实字体的吻合度，应让布局使用与 PDF 相同的字体度量表（同一 TTF 生成 metrics），而不是换浮点。

## 复现

```sh
cargo test -p soma-eval --test perturbation -- --ignored --nocapture
```
