# 真实语料与代理标定（`corpus/zh`）

状态：**已建语料 + 已跑代理标定**。这不是 Gate Q：语料没有人工偏好标注，
结论只对“可观测版面量”负责。

## 1. 语料

`corpus/zh/` 九篇文件 + 三个结构化 fixture，共 12 个文档、598 块、1214 行、48 页
（A5、10.5pt、1.6 行距）：

| 文件 | 文体 | 压测点 |
|---|---|---|
| `technical.md` | 技术说明 | 长段落、标题、强调、英文术语 |
| `notice.md` | 通知 | 列表、日期、数字、短段落 |
| `abstract.md` | 论文摘要 | 密集标点、分号、术语混排 |
| `editorial.md` | 评论 | 长句、引号、破折号、节奏 |
| `mixed.md` | 中英混排说明 | URL、行内代码、连字符、百分号 |
| `classics.md` | 古文选读 | 公共领域长段落、分页、引号 |
| `footnotes.md` | 脚注密集说明 | 脚注区、标记行耦合 |
| `interview.md` | 访谈 | 长问答、引号、粗体问号、破折号 |
| `science.md` | 科普 | 括号、英文术语、数字、上标 |
| `table-page`（内置） | 表格 | 单元盒、colspan/rowspan、表头重复、跨页 |
| `math-page`（内置） | 公式占位 | 对象盒、顺序与分页 |
| `book`（内置） | 30 章长篇 | 长篇稳定性、810 行、30 页 |

来源：散文部分为本仓库原创；`classics.md` 为公共领域古籍节选（陶渊明、范仲淹、
韩愈、欧阳修、王羲之、苏轼），使用现代通行标点，不作校勘；表格 fixture 由代码构造，
因为 `soma-md` 尚未解析表格。全部按 `prd.md` 的样本政策以 CC-BY-4.0 提供。
规则见 `corpus/README.md`。**它不是质量标注语料，也没有评审意见。**

读法：

- 孤行/寡行 **0**；跨页段落 3 次（`editorial`、`footnotes`、`science`）。
- 压缩越过 shrink 下限 **2 行 / 1214 行**，仍集中在 `notice` 与 `technical`。
- 底部留白 P95 = **486‰**，最大 **1580‰** 来自 `footnotes`：脚注区把正文挤到下一页，
  这是脚注与分页耦合的真实代价。
- `book` 30 页/810 行，0 越界、抖动 337‰，说明分页在长篇上稳定。
- `table-page` 的单元是单行短文本，抖动 0；列宽、colspan 与 rowspan 由布局计算，
  续表每页预留并重画表头（第 2 页多出 1 行表头）。语料模板用三线表
  （`outer-rule-width: 0.8pt`、`header-rule-width: 0.6pt`、无内线），
  第 2 页多出的两条线把底部留白从 361‰ 降到 278‰。

### 一次被 fixture 抓到的真实教训

表格 fixture 最初是 4 列、每格 20+ 字。在 A5 上每列只有约 7 字宽，
结果 110 行里有 **30 行压缩越界**，页面底部留白 P95 达到 3361‰。
原因不是分页，而是表格单元**继承正文样式**（首行缩进 2em），而模板没有
“单元格里的段落”这种选择器（D47）。改成 3 列、短文本后指标回到 0；
但这说明表格排版需要单元级样式，而不是让正文样式硬套。

这轮又把 fixture 扩到 rowspan 与表头重复：页面只在没有被跨行单元穿过、
也不在表头内部的**行边界**断开，所以跨两行的单元始终完整地留在同一页，
续页在顶部预留表头高度并整体平移该带的单元块（ADR-0017/0018）。
指标仍然为 0；剩下的限制是嵌套盒子与行线（D51 的剩余项）。

## 3. 代理标定：tolerance × badness scale

按“先少压缩越界、再少留白、再少抖动、再少页数、最后偏好 preset 的 scale=100”排序：

```
tolerance,scale,over_compress,emergency,page_free_p95,jitter_p95,pages
1500,100,0,0,486,337,44
1500,50,0,0,486,337,44
1500,200,0,0,486,337,44
2000,100,2,0,486,337,44
2500,100,2,0,486,337,44
3000,100,2,0,486,337,44
...
```

结论（仅限本语料与代理指标）：

- `tolerance = 1500` 把压缩越界从 2 行降到 0，页数不变（48 页）。
- 在加入长篇与表格后，抖动与留白的分位值由 `book`/`footnotes` 主导，
  `tolerance` 对它们的影响不可见；真正的可观测收益仍是“过压行归零”。
- `scale` 在 `1500` 时几乎不敏感（50/100/200 并列）；保留 `100`
  可避免无谓改动。
- 因此**如果**要新增一个“中文书版” preset，候选值仍是
  `tolerance = 1500`、`badness_scale = 100`、垂直参数保持 `default_v1`。

## 4. 不做什么

- **不修改 `default-v1`**。preset 是冻结标识；改默认值必须新增 preset id 并走 ADR
  （架构 §9）。本报告只提供候选值。
- **不宣称质量提升**。压缩越界、留白、抖动是可测量量，不等于“更好看”。
  Gate Q 仍然需要真实语料 + 至少 5 名评审的盲测（D01）。
- **不外推**。12 个文档/1214 行（含 30 页长篇与跨页表格）能发现明显的参数问题，
  但仍缺真实公式排版（D52）、rowspan 与表头重复（D51）、整本书稿的目录/章节页，
  也没有人工偏好标注。

## 5. 复现

```sh
bash scripts/corpus.sh
# 或
cargo run -p soma-eval --release -- corpus --dir corpus/zh
cargo run -p soma-eval --release -- calibrate --dir corpus/zh \
  --tolerances 1500,2000,2500,3000 --scales 50,100,200
```

`scripts/gate-q.sh` 会运行 `corpus` 的结构断言（无孤行/寡行、压缩越界有预算、
确定性）并打印上面的表。
