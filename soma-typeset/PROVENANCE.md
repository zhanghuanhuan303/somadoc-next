# Provenance

This workspace is a **clean-room** implementation of the brief in
[`../prd.md`](../prd.md) and the frozen architecture in
[`docs/architecture-v2.md`](docs/architecture-v2.md). The normative public
contract is the architecture and the ADRs. It does not include, copy, or
reference code from a prior Typst project.

No path or git dependency points at a Typst-based project.

## Public references

- The PRD ([`../prd.md`](../prd.md)) and this workspace's own architecture/ADR documents.
- The published Knuth-Plass line-breaking algorithm description.
- CLReq / GB/T and publisher practice for Chinese rules, cited by clause; tables
  are not copied wholesale.
- Rust standard library and public crate documentation.

## Font metrics table

`soma-metrics` ships `crates/soma-metrics/data/noto-cjk.smt`: **numbers only**
(advance widths, ascent/descent/leading, space width, ink bearings, the math
face's `MATH` constants and vertical variant metrics), extracted from three
open fonts. The table stores no outlines. The only font binary in the
repository is the bundled math face described below. The committed blob is
`soma.metrics/7`; the per-glyph ink (`soma.metrics/3`) and the math data
(`soma.metrics/5`–`7`, ADR-0070/0075/0076) are still integers — no outline data is
stored or shipped with the table.

| face | source | SHA-256 of the source file |
|---|---|---|
| serif | Noto Serif CJK SC, face 2 of `NotoSerifCJK-Regular.ttc` | `5d9c31a059600193c9d7968a998bde886ccdc77e934006ad243b41794c496a7d` |
| sans | Noto Sans CJK SC, face 2 of `NotoSansCJK-Regular.ttc` | `b76b0433203017ca80401b2ee0dd69350349871c4b19d504c34dbdd80541690a` |
| math | New Computer Modern Math, `NewCMMath-Regular.otf` | `60394d357348f68cd301764fe61cc502a5858e1c4ff21b948a1d14d82586a7a2` |

Both CJK families are distributed under the **SIL Open Font License 1.1**;
New Computer Modern Math uses the **GUST Font License**. The extracted table is
a factual measurement, regenerated by `tools/metrics-gen` (see
`docs/adr/0012-table-metrics.md`). For a CFF math face the generator runs the
Type 2 charstrings to record vertical ink (ADR-0078); without it a radical
cannot sit on its radicand and an operator cannot be centred on the axis.

`examples/book/metrics-lxgw.smt` is a layout baseline built the same way from
**LXGW WenKai** (SIL OFL 1.1), with a Medium face used as bold and New
Computer Modern Math as the math face. It exists so `--metrics` reproduces the
same line breaks without the font installed; the PDF still needs the font file
to embed outlines.

`examples/templates/plex.smt` is the Plex reference template's table, measured
from **IBM Plex Sans SC** (SIL OFL 1.1) and **New Computer Modern Math** (GUST
Font License). It stores numbers only. It is committed because the
browser-local Studio embeds it: a fresh clone can build the wasm UI without
installing a font or regenerating a table.

The CJK and LXGW families are under the SIL OFL 1.1; New Computer Modern Math
is under the GUST Font License. Both permit redistribution of derived
measurements. The licence text is available from each font distribution.

## Bundled math face

`crates/soma-cli/assets/NewCMMath-Regular.otf` is the one font binary this
repository distributes. It is bundled with the CLI, not the library crates, so
`soma render --format pdf` has the face the embedded table was measured from on
a machine with no TeX installation (ADR-0079).

| item | value |
|---|---|
| face | New Computer Modern Math, `NewCMMath-Regular.otf` |
| SHA-256 | `60394d357348f68cd301764fe61cc502a5858e1c4ff21b948a1d14d82586a7a2` |
| licence | GUST Font License |
| licence text | `crates/soma-cli/assets/GUST-FONT-LICENSE.txt` |

The face is used only after its advances agree with the metrics table; a custom
table measured from another math face makes the CLI probe installed faces
instead. Apart from this file, the repository does not redistribute font files.

## Browser Studio fonts

The hosted Studio and the browser-local mode do not commit font binaries. They
generate GB2312 levels 1+2 subsets into `dist/fonts/v2/` from IBM Plex Sans SC,
Noto Sans Mono and New Computer Modern Math with `scripts/local-assets.sh`.
IBM Plex Sans SC and Noto Sans Mono are SIL OFL 1.1; New Computer Modern Math
is GUST Font License. The generated files are deploy artifacts, not repository
assets. The proof and PDF exporter share them; characters outside GB2312 are
not covered (D119).

**Known debt:** the punctuation hard rules are now `Verified` against

punctuation). The remaining debt is narrower: the trim *ratios* are

must not treat the trim amounts as sourced. Recorded in `docs/k6-report.md`
and `docs/k8-report.md`.

## Policy

- Cite clauses, do not reproduce tables. The project references the relevant
  clause or paragraph; it does not copy a standards table wholesale.
- `Tbd` rules are soft rules only: they may emit `Allowed` + penalty/trim, never
  `Forbidden` / `Forced`. A hard rule requires `Verified` status. Promoting a
  rule to `Verified` requires a cited clause in its `source` field.
- GB/T is a recommended standard; only the applicable normative text is cited.
  Any quoted excerpt must be short, attributed, and reviewed for license
  compatibility before it is committed.
- Publisher-practice rules are recorded as practice, not as a standard; their
  provenance is the sample/edition, not a normative clause.
- New code must follow architecture v2 and the ADRs; deviations need a new ADR.
